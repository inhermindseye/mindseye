The network

  • drag circles (“nodes”) or zoom the chart in and out to focus on specific areas
  • hover over nodes or lines (“links” or “edges”) for additional information
  • hover over a node also highlights that person’s connections
  • click on the node to make it stick so you can take a closer look (click again anywhere else to reset)

Notes and caveats

This is an exploratory chart, and shouldn’t be taken too seriously. It may suggest connections and groupings among individuals; but apparent links may be illusory, and stronger real links might be obscured by the limitations of the data. (It should be noted, for example, that Alice Thornton herself is a relatively minor presence in the chart because she rarely referred to herself in the third person and we chose not to tag first person references.)

The chart only shows a subset of all possible connections in the ATB data, to make it more legible:

  • it’s restricted to events that began between 1651 (the year Alice Thornton married) and 1669 (the year after her husband died)
  • some minor or fragmentary events have also been removed
  • individuals must have at least 15 connections to be included
  • pairs of individuals must have at least 2 connections for the link to be shown

Connections between people are made on the basis of co-occurrence in tagged mentions of events in the Books. (Each name is counted once per event mention, which can have the effect of boosting the presence (and connections) of those who appear in certain events that Thornton told multiple times in her Books.) There’s no attempt to measure the nature of those connections; people may be mentioned in passing in an event and not directly interact with others who were more central to the narrative. Even so, the juxtaposition usually suggests there’s some kind of link between them.

Some features of the graph are designed to help consider the strength of connections: the size of nodes reflects (to some extent) how many connections an individual has overall, and the width of the links reflects the number of times a pair of individuals co-occur. (Hover over nodes and links to see actual numbers.)

Subject keywords were assigned to events by the project; I counted pairs’ shared keywords and used the top ranked keyword as a way to categorise the association between them. This seems to highlight a number of clusters in the network quite pleasingly, but hasn’t been tested out at all; at the level of individual pairs it might not necessarily feel like the most accurate representation of a relationship. (Some pairs could be very heavily skewed towards a particular keyword, but others were more evenly distributed.)

Resources

The chart has been made primarily using D3.js and ObservableJS. A number of Observable Notebooks were key resources for specific aspects:

  • Lanchester family network (curvy lines and link categories)
  • Network graph with d3.force grouping (highlighting and tooltips)
  • Plot: Legends (standalone legend)

I also reused some of the code (and experience) of making network charts for a previous project, Beyond Notability.

// function for the curved edges, don't ask me how it works lol.

function linkArc(d) {
  const r = Math.hypot(d.target.x - d.source.x, d.target.y - d.source.y);
  return `
    M${d.source.x},${d.source.y}
    A${r},${r} 0 0,1 ${d.target.x},${d.target.y}
  `;
}

// drag function

function drag(simulation) {
  
  function dragstarted(event, d) {
    if (!event.active) simulation.alphaTarget(0.3).restart();
    d.fx = d.x;
    d.fy = d.y;
  }
  
  function dragged(event, d) {
    d.fx = event.x;
    d.fy = event.y;
  }
  
  function dragended(event, d) {
    if (!event.active) simulation.alphaTarget(0);
    d.fx = null;
    d.fy = null;
  }
  
  return d3.drag()
      .on("start", dragstarted)
      .on("drag", dragged)
      .on("end", dragended);
}
